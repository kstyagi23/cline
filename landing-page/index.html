THEN, MAKE THE CONNECTION.

Bring your intelligence.

After setup, run bun link from apps/cli to put glyph on your PATH. Configure your provider, then start a session.

glyph auth↗

Without linking, use bun run cli from the repository root.

↳ Glyph is distributed from this fork, not a Glyph registry package. Installing upstream Cline does not install Glyph. Rebuild this fork rather than using glyph update.

A note on approvals and isolation +

Glyph starts in Act mode with tool auto-approval enabled unless settings or flags override it. Use --auto-approve false to review tool actions. Worktrees start from committed HEAD, not uncommitted changes. An isolated --data-dir separates application state; it is not a filesystem security sandbox.
